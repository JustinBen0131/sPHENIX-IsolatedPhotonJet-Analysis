# External reference data

## atlas_plb789_167_table1_xjgamma.csv

ATLAS, "Measurement of photon-jet transverse momentum correlations in 5.02 TeV
Pb+Pb and pp collisions with ATLAS", Phys. Lett. B 789 (2019) 167,
arXiv:1809.07280, INSPIRE 1694678.  HEPData record 85369, Table 1,
DOI 10.17182/hepdata.85369.v1/t1.

Columns: `series` (pp, PbPb_0-10, PbPb_10-20), photon pT range in GeV,
xJgamma bin edges, the published `(1/N_gamma) dN/dxJgamma` value, and its
statistical and systematic uncertainties.

Photon pT is 63.1 to 79.6 GeV, far above the sPHENIX 15 to 35 GeV range, so an
overlay with the sPHENIX result compares shapes across very different
kinematics.  It is a visual reference, not a like-for-like comparison.

The values were transcribed from HEPData Table 1 into the maintained overlay
script and copied here unchanged; they were not re-downloaded when this file
was written.  Verify against the record before using them in a publication.
